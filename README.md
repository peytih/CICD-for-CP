# CICD-for-CP

validate — проверка, что все файлы на месте                                                
dependencies — установка зависимостей                                             
security — проверка на уязвимости (Trivy)                                                    
build — сборка Docker-образа                                    
test — запуск и проверка, что приложение отвечает                                      
deploy — вручную: деплой на сервер по SSH                    

В GitLab: Settings → CI/CD → Variables добавьте:                           
 SERVER_ADDRESS — Адрес сервера, например user@192.168.1.10                                
 DEPLOY_SSH_PRIVATE_KEY — Приватный SSH-ключ для доступа к серверу

Встроенные меры защиты:                       
 Запуск приложения от пользователя appuser (не root)                      
 Использование slim-образа для минимизации поверхности атаки                           
 Сканирование уязвимостей через Trivy (CVE, лицензии)                            
 Поиск секретов в коде через Trivy fs                            
 Маскирование чувствительных переменных в GitLab                    

После успешного прохождения тестов:                       
Перейдите в CI/CD → Pipelines             
Нажмите на последнюю сборку              
Нажмите Play на стадии deploy
